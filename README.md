# Topological Field Model Based on Hopf Fibration and Beltrami States

**Author:** Damyan Damyanov  
**Affiliation:** Independent Researcher, Hisarya, Bulgaria  
**Contact:** damione1@gmail.com  

## Abstract
This repository contains the LaTeX source code and full compiled manuscript for the topological field model deriving the Standard Model mass spectrum and fundamental constants through Hopf fibration ($S^3 \to S^2$) and Beltrami vector fields.
